# 价格观察台界面设计

## 设计目的

面向在本机管理待购商品的用户。首页先帮助用户找到商品并快速回看关注项；详情页帮助用户根据已有报价、采样来源与购买偏好判断下一步。

本轮采用 `frontend-design` 的“先确定内容和方向，再实现与截图复核”流程。原有概况数字占据主任务上方，多个页面的字号与间距层次接近。调整后搜索先出现，关注项紧邻搜索，统计作为辅助信息；价格详情以报价、曲线和建议为主。

## 视觉约定

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 冷瓷白 | `#F3F6FA` | 工作区背景 |
| 深海蓝 | `#183B49` | 导航与详情报价区 |
| 青蓝 | `#087F86` | 主操作与报价曲线 |
| 薄荷 | `#E4F3F1` | 选中状态与价格位置 |
| 琥珀 | `#A95618` | 低价提醒与最低价参考线 |
| 墨色 | `#182B3B` | 正文与标题 |

标题和价格使用本机 Bahnschrift / DIN Alternate，中文回退 PingFang SC / Microsoft YaHei；正文使用 Segoe UI 与对应中文字体；步骤数字使用 Cascadia Code / Consolas。字体均有系统回退，不请求外部字体服务。

特色集中在价格详情：深海蓝报价区与可逐条查看的青蓝曲线，帮助区分“最近报价”“全历史采集最低”和“正在查看的某条采样”。其余界面使用浅色面板、清楚的标签和适量留白。

初稿复核时，去掉页面和商品弹窗中的英文装饰标语，以及数据来源分类中的装饰序号；仅在真实的“搜索 → 确认规格 → 监控”流程中保留步骤编号。没有加入装饰性价格曲线或虚构商品趋势。

```text
桌面首页                        商品详情
导航 | 标题、演示标识            商品与所选规格
     | 商品搜索 | 正在关注       最近报价 / 全历史采集最低
     | 轻量概况                  报价曲线与采样 | 建议与监控管理
     | 低价提醒

手机：顶部导航 → 标题 → 搜索 → 关注项 → 概况 → 提醒
详情：报价 → 曲线与采样 → 建议 → 监控管理
```

## 组件与交互

- `WatchPreview` 在首页展示最多两项已有监控，从当前 dashboard 数据投影，不额外发请求。
- `PricePosition` 只描述后端返回的整数分金额与记录数。只有一条记录时显示“首条报价 · 待积累”；多条记录且当前价等于采集最低时显示“与采集最低持平”。这个展示不表示新低事件、报价新鲜程度或购买建议。
- `PriceChart` 继续使用观测时间和整数分金额定位，保留整个历史的最低参考线。指针可选中最近横坐标的实际采样；前后按钮支持键盘和触控逐条查看，显示时间、金额和来源。通过 ResizeObserver 按容器宽度计算坐标，手机上保持坐标文字可读；离页清理观察器。没有记录时显示空状态，只有一条时显示单点。
- 监控列表在窄屏改为商品信息与双报价布局，显式标注当前价和采集最低价。
- 保留搜索进度、错误原因、模型补正、建议来源与过期提示；演示模式持续可见。
- 动画只用于按钮、导航与列表状态过渡，并遵循减少动画偏好。保留跳到主内容、可见焦点、弹窗焦点约束和至少 44px 的主要触控入口。

业务规则、模型设置、用户数据库与后端接口沿用已有实现。页面组合组件，异步流程仍由 composables 和 API 层管理；新增展示组件不直接调用网络。

## 验证记录

2026-11-06 在 Windows 独立演示环境完成以下验证，使用虚构目录、导入的演示报价与规则建议，没有读取用户数据库或调用外部模型。

- 30 项前端测试、113 项 Python 单测、TypeScript / Vite 生产构建、Ruff 和 Git 空白检查通过。新增曲线测试验证 260 / 680 / 1100 像素绘图区内的真实时间比例、最低参考线，以及单条和空记录。
- Playwright 检查 320 / 390 / 768 / 1440 / 1920 像素宽度下的首页、监控列表、单品详情、搜索历史、提醒、数据管理和模型设置，共 35 项，无横向溢出或页面异常。
- 实际操作完成目录搜索、详情查看、选择白色规格、加入监控及从列表进入详情。新规格显示“首条报价 · 待积累”，曲线只有一个点、没有连线。加入监控后仍可从搜索记录找回四个候选。
- 曲线用键盘 Enter 操作上一条记录，读数从 ¥49.90 变为 ¥52.90；移动指针到首条后显示 ¥59.90，与对应的时间和来源一致。390 像素视口下实际绘图区为 312 × 205，坐标文字保持 11px。
- 手机规格弹窗无溢出，Esc 关闭后焦点回到原“查看详情”按钮；展开高级模型参数后无溢出。减少动画偏好下，曲线按钮的过渡和动画时长均为 0。
- 预算 60 元、近期购买的规则分析返回“可考虑购买”；演示截图保留建议来源、数据说明及完整规格。README 和八张功能截图同步更新。

实际页面截图见 [功能演示](demo.md)。本轮验证覆盖界面和既有规则流程，未重新评测外部模型的商品筛选质量。
