# 商品目录

程序接收 UTF-8 JSON 数组。随包的 12 个商品均为虚构演示；自行提供的目录请放在忽略的 `local-data/` 下，启动时传入 `--dataset`。

```json
[
  {
    "asin": "MY-CUP-001",
    "title": "500ml 不锈钢保温杯",
    "category": "杯壶",
    "shop_name": "示例店",
    "full_description": "用于通勤的 500ml 保温杯。",
    "attribute": ["不锈钢", "500ml"],
    "pricing": [59.9],
    "customization_options": {
      "颜色": [
        {"value": "黑色", "is_available": true, "price": 59.9},
        {"value": "白色", "is_available": true, "price": 59.9}
      ]
    }
  }
]
```

`asin` 是稳定且唯一的公开商品 ID，不要求使用某个平台的实际 ASIN；`title` 是商品标题。没有选项时使用空对象。`pricing` 是公开价格列表，有多个不同价格时表示范围，必须能从规格报价确定最终价格才可监控。每个规格组的价格表示该选择对应的**完整商品报价**，多个组的价格不会相加；冲突报价会被拒绝。

索引仅使用标题、副标题（`sub_title`）、分类、属性、选项文本和介绍。任务答案、用户画像与隐藏标注不用于搜索；建议直接提供只有公开商品字段的目录。导入目录前应保证 ID 唯一、金额有效且文本来源允许使用。

## 价格快照

从页面“数据管理”生成带正确监控 ID 的模板，再更新实际价格及带时区的观测时间：

```json
{
  "observations": [
    {
      "watch_id": "替换为实际监控ID",
      "price": "49.90",
      "observed_at": "2026-11-03T10:00:00+08:00",
      "currency": "CNY",
      "mode": "snapshot"
    }
  ]
}
```

时间不得晚于导入时刻。事件模拟的手动报价使用 `mode=simulation`，固定场景回放拒绝手动报价。反复检查相同静态快照不会产生新的观测；监控本身不会从真实购物平台自动拉价。
